# Escape-of-the-princess-game

I made this game using Construct 3.

Just try and enjoy it.

# Play
You are a princess. Ypo are going to escape from the eerie dragon's dungeon. Try to collect coins and kill dragons. To kill the dragon you need to press the spacebar five times. The princess's arrows will kill him. Then you can collect the coin dropped from his death. You need to collect as many coins as possible and make sure the dragon doesn't eat you. Be careful!
